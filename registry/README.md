# Master Registry Workspace

The Master Registry is the controlled source for entity identity and status.

The supplied catalogue explicitly requires:

- no product without Registry ID;
- no new layer without Architecture Review;
- no new entity without Classification;
- no major change without Change Record.

Until WI-MR-002 is present in this repository at an approved baseline, this directory must not invent official IDs. Proposed entities are tracked as TBD/Proposed only.

## Required entity fields

Registry ID, canonical name, Persian name, entity type, layer, domain, status, definition, purpose, capabilities, audience, prerequisites, dependencies, interfaces, governance, security, data, legal/rights, availability, access, owner, related entities, source documents, version and change history.
