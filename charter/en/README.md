# Eternal Wisdom Charter

This directory contains the official English edition of the **Eternal Wisdom Charter**.

**Short name:** Wisdom Pact  
**Master project name:** Wisdom Intercessor

The Persian and English editions are controlled parallel editions and must remain aligned in document identity, version, status, and meaning.

Files using the former **Global** title are legacy artifacts. They must not be deleted or moved until canonical replacement files have been created and verified.

Document status is governed by **WI-MR-001 — Master Registry & Document Control**.
