# Charter / WisdomPact

This directory contains the foundational pact and charter materials of WisdomIntercessor.

WisdomPact is the foundational pact/documentation domain of the project. The master project and ecosystem name remains **WisdomIntercessor**.

Documents in this directory may exist in Draft, Review, Approved, Superseded, Archived, or Deprecated states. The applicable status is controlled through WI-MR-001 — Master Registry & Document Control.

Draft material is open to critique and revision and must not be represented as final or absolute.

Where Persian and English versions exist, they should preserve the same document identity and controlled version relationship.
