# Eternal Wisdom Charter / Wisdom Pact

This directory contains the foundational **Eternal Wisdom Charter**, also referred to in its short form as the **Wisdom Pact**.

The master project and ecosystem name remains **Wisdom Intercessor**. “WisdomPact” is the repository/domain name for the charter and its controlled documentation.

## Document control

All charter materials are subject to **WI-MR-001 — Master Registry & Document Control**.

Controlled statuses are: Planned, Draft, Review, Approved, Superseded, Archived, Deprecated.

A file existing in this repository does not by itself mean that the document is approved or published.

## Language alignment

The Persian and English editions are parallel controlled editions of the same foundational document.

**فارسی:** منشور حکمت جاویدان  
**English:** Eternal Wisdom Charter  
**Short name:** Wisdom Pact

The former word **Global** is not part of the official title. Existing filenames containing “Global” are legacy artifacts and must be aligned only after canonical replacements are verified.

## Canonical source

`charter/CHARTER.md` is reserved for the canonical Markdown representation of the approved Charter.

Until the approved source text is imported and verified, `CHARTER.md` must not be treated as a completed or authoritative transcription.

## Release policy

Charter releases must preserve document identity, version, language alignment, and revision history. Superseded or legacy artifacts may be retained under `charter/releases/` for traceability.

GitHub commits are documentation changes; they do not automatically publish the Charter to the public website or activate any governance, financial, identity, wallet, or external-service function.
