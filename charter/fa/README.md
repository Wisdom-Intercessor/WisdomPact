# منشور حکمت جاویدان

این پوشه شامل نسخه فارسی رسمی **منشور حکمت جاویدان** است.

**نام رسمی انگلیسی:** Eternal Wisdom Charter  
**نام کوتاه:** Wisdom Pact  
**نام رسمی پروژه:** Wisdom Intercessor

نسخه فارسی و انگلیسی باید از نظر هویت سند، شماره نسخه، وضعیت کنترل‌شده و معنای اصول هم‌تراز باشند.

نسخه‌های دارای عنوان یا نام فایل قدیمی شامل واژه «Global» آثار legacy محسوب می‌شوند و تا زمان ایجاد و بررسی نسخه‌های canonical نباید حذف یا جابه‌جا شوند.

وضعیت هر نسخه مطابق **WI-MR-001 — Master Registry & Document Control** کنترل می‌شود.
