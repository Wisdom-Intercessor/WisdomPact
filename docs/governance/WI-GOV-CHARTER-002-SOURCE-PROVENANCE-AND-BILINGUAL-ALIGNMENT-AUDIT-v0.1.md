# Eternal Wisdom Charter — Source Provenance and Bilingual Alignment Audit

**Document ID:** WI-GOV-CHARTER-002  
**Version:** 0.1.0-draft  
**Status:** Review proposal  
**Purpose:** Record verified source paths, distinguish canonical text from control documents, and define a safe verification workflow for Persian/English alignment.

## 1. Scope and limitation

This is a repository-path and document-control audit based on files directly inspected in the WisdomPact default branch. It is not a full text comparison of every charter draft, historical release, attachment, or external source. The primary approved Charter text has not yet been positively identified and verified in this audit.

## 3. Canonical-source status

The charter README reserves `charter/CHARTER.md` for the canonical Markdown representation of the approved Charter. The same README explicitly states that until the approved source text is imported and verified, that path must not be treated as authoritative or complete.

Therefore, the canonical source is **not confirmed by this audit**. No document is promoted to Approved by this inventory.

## 4. Bilingual control

The Persian and English editions are intended as parallel controlled editions:

- Persian title: **منشور حکمت جاویدان**
- English title: **Eternal Wisdom Charter**
- Short name: **Wisdom Pact**

A future alignment review should verify, section by section:
1. Same document ID and version.
2. Same principle/section sequence and scope.
3. No omitted, added, or materially altered rights, duties, limits, or definitions.
4. Consistent terminology and translation of normative verbs.
5. Cross-language change log and review evidence.
6. Approval status independently recorded; a matching translation is not itself approval.

## 5. Legacy naming

The charter README states that **Global** is not part of the official title and that legacy filenames containing “Global” should only be aligned after canonical replacements are verified. Preserve legacy artifacts for traceability; do not rename, delete, or supersede them solely based on filename.

## 6. Next verification work

Before importing or declaring a canonical Charter:
- Identify the actual source document(s) and their origin, date, author/translator, language, and version.
- Inspect the complete Persian and English texts, not only titles or summaries.
- Compare section structure and meaning; document unresolved discrepancies.
- Verify any approval evidence separately from draft or publication evidence.
- Create a controlled canonical transcription only after source identity and approval status are verified.
- Keep the website and external publication unchanged unless separately authorized.

## 7. Participation annex boundary

The proposed participation annex and its companion architecture remain proposals unless their approval records are verified. Do not silently incorporate them into the Charter text.

## 8. Change and activation safeguards

This audit is a documentation proposal. It does not approve the Charter, establish governance authority, publish material to the live website, or activate identity, financial, token, wallet, referendum, or external-service functionality.
